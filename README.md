# Event Tracking App – Portfolio Reflection
 App Requirements and Goals
I developed an Android Event Tracking App that allows users to create accounts, log in, and manage events. The goal was to provide a simple and organized way for users to track important events and dates.

 User Interface and Design
The app includes login, account creation, event listing, and event management screens. I focused on creating a user-friendly interface with clear navigation, organized layouts, and accessible buttons to make the app easy to use.

 Coding Approach
I developed the app using Java in Android Studio, incorporating SQLite for local data storage. I used modular programming and incremental development to keep the code organized, maintainable, and easier to troubleshoot.

 Testing and Functionality
I tested the app using the Android Emulator to verify navigation, login functionality, event creation, and database interactions. Testing helped identify issues and ensure the application worked as intended.

 Challenges and Innovation
One challenge was connecting the user interface to the database while maintaining smooth navigation between screens. I addressed this by troubleshooting individual components and testing each feature throughout development.

 Successful Component
I was particularly successful in implementing the event management functionality. Connecting the event creation screen to SQLite and displaying saved events demonstrated my understanding of Android development, database integration, and user-centered design.
